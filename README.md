# Documentation

## Dev

1. Run `npm i`
2. Set `ENV` args (see below)
3. Run `npm run dev`

## Build
1. Run `npm run format`
2. Fix warns and errors
3. Run `npm run build`
4. Run `npm run start`

## Development

Create `.env` and write:

```env
REACT_APP_API_URL = https://192.168.10.23:5001
TEST_SERVER_IP = localhost
TEST_SERVER_PORT = 3000
REACT_APP_MODE = 'development'
```
