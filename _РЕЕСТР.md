## Поведение при 401 (истёкшая сессия)

**Было:** при истёкшей сессии возможен тихий белый экран; redirect без сообщения; title с пустым суффиксом (ранее).

**Стало:**
- Любой 401 на защищённых страницах → одна попытка refresh (dedupe) → при неудаче `POST /api/Auth/logout` + redirect на `/auth/login?sessionExpired=1`.
- На странице логина показывается toast «Сессия истекла» / «Session expired».
- `DesigningRouteGuard` при отсутствии профиля редиректит на логин (вместо бесконечного loader).
- Document title формируется как `{название страницы} | devBIM` через `RoutePageTitle`.

**Как проверить:**
1. Войти в систему, открыть `/designing/main`.
2. Очистить cookies сессии в DevTools или дождаться истечения токена.
3. Обновить страницу или выполнить любое действие с API.
4. Ожидается redirect на `/auth/login?sessionExpired=1` и toast «Сессия истекла».
5. Проверить title вкладки на ключевых страницах (главная, справочники, конструктор) — суффикс `devBIM`.
